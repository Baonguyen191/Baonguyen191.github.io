Nội dung bài tập

1

Tên miền miễn phí

GitHub Pages cấp sẵn subdomain baonguyen191.github.io. Có thể đăng ký thêm tên miền .id.vn miễn phí tại P.A Việt Nam hoặc Mắt Bão, rồi trỏ về GitHub Pages bằng bản ghi CNAME.

2

Web hosting miễn phí

Dùng GitHub Pages: host trang tĩnh (HTML/CSS/JS) trực tiếp từ repository, có HTTPS miễn phí.

3

Repository Git – GitHub

Mã nguồn quản lý bằng Git, đẩy lên repository Baonguyen191.github.io. Mỗi lần git push lên nhánh main, trang tự động cập nhật.

Các lệnh Git đã dùng

git init
git add .
git commit -m "Add personal page"
git remote add origin https://github.com/Baonguyen191/Baonguyen191.github.io.git
git push -u origin main
